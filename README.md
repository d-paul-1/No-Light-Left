## 1. Introduction

**No Light Left** is a horror escape game where the player must navigate a haunted mansion, avoid a lurking monster, and collect five scattered dolls. Once all dolls are collected, a key is granted that unlocks the door on the top floor—allowing the player to escape and complete the objective.

---

## 2. Project Overview

### Premise
You're trapped in a dark mansion. To escape, you must collect a set of dolls hidden throughout the environment—all while being hunted by a monster. There is a time limit, and survival depends on your awareness and speed.

### Project Criteria

- **Execution**: Implemented interactive elements including doors, keys, a monster, and win/loss conditions. The horror experience was achieved through sound, lighting, and gameplay.
- **Creativity**: The random doll placement, immersive atmosphere, and use of light as a defense mechanic contributed to a unique experience.
- **Appeal**: The detailed environment and anticipation of the monster encounter enhanced player engagement.
- **Functionality**: Core features worked as intended, with minimal bugs that did not significantly disrupt gameplay.

---

## 3. Project Showcase

### Key Features

- Collectible dolls that spawn randomly across the map
- Real-time monster AI using NavMeshAgent and animation control
- Interactive door and key system
- Flashlight mechanic to freeze the monster
- Horror-focused environment with atmospheric audio and visuals
- Full game loop: win by escaping or lose by running out of time or being caught

---

## 4. Comparison to Original Goals

### Successes

- Monster behavior worked as intended, including flashlight freezing logic
- The mansion design was atmospheric and immersive
- UI elements (timer, health, doll count) functioned cohesively to support gameplay

### Pivots

- Originally intended to include puzzle-solving elements, but prioritized core escape gameplay instead
- Planned multiple levels or mansion sections, but focused on refining a single detailed environment due to time constraints

---

## 5. Development Challenges

- UI Design: Fine-tuning timers, health bars, and other interface components was time-consuming
- Monster Behavior: Synchronizing the NavMeshAgent with the animation controller and implementing the flashlight freezing mechanic required iteration and debugging
- XR Origin Issues: The player occasionally fell through the floor or was stuck at ground level, even with proper collider setup and calibration. This was especially problematic when using XR devices

---

## 6. Feedback and Future Extensions

### Feedback

Playtesters appreciated the horror atmosphere and suspense. Suggestions included:
- Adding more threats or chase intensity
- Incorporating puzzle elements
- Introducing multiple endings

### If We Had More Time

- Implement more puzzle-based challenges
- Add additional areas or levels to explore
- Improve monster AI (e.g., patrol behavior, hiding mechanics)
- Optimize for XR to resolve movement issues and enhance immersion
